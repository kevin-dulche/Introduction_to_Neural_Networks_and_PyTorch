# Training Linear Regression Models the PyTorch Way

In this module, you'll discover how to implement training workflows using PyTorch tools such as DataLoader and optimizers. You'll learn how to compare batch, stochastic, and mini-batch gradient descent, and examine how batch size, epochs, and learning rate affect convergence. You'll learn how to structure full training loops with forward passes, backpropagation, and parameter updates. Finally, you'll explore training, validation, and test splits to evaluate model performance and detect overfitting.

1. Identify how dataset splitting helps detect overfitting.
2. Explain how validation loss differs from training loss in model evaluation.
3. Define the roles of training, validation, and test datasets.
4. Explain the purpose of the learning rate as an optimizer hyperparameter.
5. Recognize the function of PyTorch optimizers in parameter updates.
6. Identify the main steps in a standard PyTorch training loop.
7. Describe the role of the PyTorch DataLoader in training workflows.
8. Recall the purpose of batch size, epochs, and iterations in model training.
9. Identify the difference between stochastic, batch, and mini-batch gradient descent.
10. Define stochastic gradient descent (SGD) and describe how it updates model parameters.
