## I. Cost vs. Loss Function

| Term | Scope | Definition | Purpose | Example |
| :--- | :--- | :--- | :--- | :--- |
| **Loss Function** | Single Sample (Single prediction). | Measures the error for *one* data point ($\mathbf{L} = f(\hat{y}_i, y_i)$). | Provides immediate feedback on single-point performance. | MSE loss for one house price prediction. |
| **Cost Function** | Entire Dataset (Average across $N$ samples). | Summarizes the total average error over the entire dataset ($\text{Cost} = \frac{1}{N} \sum L_i$). | Guides overall model training and parameter adjustment. | Average MSE loss over all training data. |

> **Key Takeaway:** The Loss Function is the metric for a single sample; the Cost Function is the averaged metric guiding the entire optimization process.

## II. Model Dependence (The Why)

Model predictions ($\hat{y}$) are generated by the model parameters ($\mathbf{W}, b$). Since $\text{Loss}$ depends on $\hat{y}$, and $\hat{y}$ depends on $(\mathbf{W}, b)$, it logically follows that **the Cost Function is a function of the Model Parameters.**

$$\text{Cost} = f(\mathbf{W}, b)$$

**Objective:** The goal of training is to find the optimal parameter values ($\mathbf{W}^*, b^*$) such that $\text{Cost}(\mathbf{W}^*, b^*) \to \text{Minimum}$.

## III. Batch Gradient Descent (The How)

Gradient descent is the mechanical process used to minimize the cost function.

### The Five Steps of Training
1.  **Forward Pass:** Compute predictions ($\hat{y}$) for all training samples using current parameters $(\mathbf{W}, b)$.
2.  **Calculate Loss:** Calculate the total Cost across all $N$ samples (e.g., average MSE).
3.  **Backward Pass (Gradient Computation):** Call `.backward()` to compute $\frac{\partial \text{Cost}}{\partial W}$ and $\frac{\partial \text{Cost}}{\partial b}$.
4.  **Parameter Update:** The optimizer uses the calculated gradient and the learning rate to update the parameters, moving them toward lower cost:
    $$\mathbf{W}_{\text{new}} = \mathbf{W}_{\text{old}} - (\eta \cdot \frac{\partial \text{Cost}}{\partial W})$$
5.  **Iteration:** Repeat the cycle until the loss converges or improvement stalls.

### Batch Gradient Descent Characteristics
*   **Stability:** Because it uses all $N$ samples to calculate a single, averaged gradient, the updates are highly **stable and reliable**.
*   **Drawback:** Computationally intensive; processing the entire dataset every step is slow for very large datasets.
